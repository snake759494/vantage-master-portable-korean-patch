Vantage Master Portable (1.01) Japanese kanji extraction
=========================================================
Source: pspfont.dat
Raster offset: 0x1CEC4
Raster end (exclusive): 0x80384
Tiles: 6355
Tile size: 16x16 pixels, 64 bytes
Encoding: NGP 2bpp-reverse (right-to-left groups, low two-bit pair first)
Palette: 4-color grayscale (white, light gray, dark gray, black)
JIS code range represented: 0x3021..0x7426 (non-empty kanji entries only)
The compact PNG preserves tile order; the JIS-grid PNG places blank cells for unused JIS positions.
